# Useful Side View - Código Legacy (Inamovible)

Este directorio contiene el respaldo y referencia histórica de la versión 1.x / 2.0.x del mod `useful-sideview`.

## Estado: CONGELADO / INAMOVIBLE

- Este código **no se modifica más**.
- Sirve únicamente como catálogo y biblioteca de referencia funcional (parsers de Markdown, descompresión ZIP/RAR/CBZ, lógica de thumbnails, decodificadores WIC/GDI+ y Media Foundation).
- Todo el desarrollo activo se realiza en `src/v2/` bajo el patrón canónico de ventana inyectada de Windows 11 (Quick-Look architecture) e Inyección de Dependencias.
